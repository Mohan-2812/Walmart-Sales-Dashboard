# Walmart Sales Analysis Dashboard

## Project Overview
This project focuses on analysing sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profit, quantity and geographical sales distribution.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Dashboard Features
- **Total Sales:** Displays overall sales.
- **Total Profit:** Shows total profit generated.
- **Total Quantity:** Displays total quantity sold.
- **Sales Trend Over Time:** Analyses sales based on order dates.
- **Sales by Product:** Compares sales across products.
- **Sales by Category:** Analyses category-wise sales performance.
- **Profit by Geography:** Shows profit across geographical areas.

## Interactive Filters
- Category
- Geography
- Order Date

These filters help users explore the data and analyse different business areas.

## Key Insights
- Compare sales performance across product categories.
- Identify products contributing to sales.
- Understand profit distribution across geographical areas.
- Track sales trends over time.

## Learning Outcomes

- Worked with sales data.
- Used charts, cards and slicers.
- Improved data visualization and analytical skills.
